# 👨‍💻 Personal Portfolio / CV Website



This is my personal portfolio and CV website – a modern, fully responsive, single‑page resume designed to showcase my skills, projects, and professional experience as a Front‑End Developer and UI/UX Designer.

🌐 **Live Demo:** [Abolfazl Yousefi](https://buildorab.com/pages/projects/personal/cv/cv.html)

---

## ✨ Features

- 🎨 **Modern, clean design** – Focused on readability and user experience
- 📱 **Fully responsive** – Works perfectly on mobile, tablet, and desktop
- 🌐 **Multilingual support** – Persian and English (UI language toggle)
- 📊 **Skill visualization** – Interactive progress bars for core competencies
- 🧩 **Project showcase** – Highlights key projects with technologies used
- 📜 **Academic timeline** – Displays education and certifications
- 📬 **Contact section** – Easy access to email and location info

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Custom styling with Flexbox and Grid
- **JavaScript** – Interactivity and language switching
- **Google Fonts** – Typography
- **Font Awesome** – Icons
